# 1. ModelSwap 是什么

ModelSwap 是一款开源的 AI 模型基础设施管理工具。如果你同时使用多家 AI 平台（OpenAI、Anthropic、智谱、火山方舟……），ModelSwap 帮你把散落各处的 API Key 和模型配置集中管理，一键切换。

## 1.1 解决什么问题

- API Key 分散在各平台控制台、`.env`、Agent 配置文件中，难以统一管理
- 换模型要手动改每个 Agent 的配置，容易出错
- 想让 AI Agent 帮你改配置？你得把密钥交给它——有泄露风险。ModelSwap 的 CLI 在本地管理密钥，Agent 永远不接触真实 Key
- 多台电脑之间密钥和配置无法同步

## 1.2 核心能力

| 能力 | 说明 |
|------|------|
| 密钥库 | AES-256-GCM 加密存储在本机，密钥默认脱敏展示 |
| 模型管理 | 41 个预置 Provider，统一端点与认证方式 |
| Agent 适配 | 10 个 Agent 一键切换模型，自动改配置 |
| 多端同步 | iCloud / WebDAV / Cloudflare / Supabase / 火山引擎，端到端加密 |
| 浏览器扩展 | 自动在各平台创建 API Key 并入库 |

## 1.3 组件关系

```
┌─────────────┐    ┌─────────────┐
│   桌面版     │    │   CLI 工具   │
│  (macOS)    │    │  (全平台)    │
└──────┬──────┘    └──────┬──────┘
       │ 内置浏览器扩展     │
       ▼                  ▼
┌──────────────────────────────┐
│     Web 控制台 (:3780)        │
│  密钥管理 · 模型切换 · 用量    │
└──────────────────────────────┘
              │
              ▼
   ~/.modelswap (本地加密数据)
```

- **桌面版**：同一套控制台的原生窗口（目前仅 macOS），内置浏览器扩展——**推荐的安装方式**
- **CLI**：命令行工具，同时提供 Web 控制台，macOS / Linux / Windows 通用
- **Web 控制台**：管理密钥、切换模型、查看用量的主界面
- **浏览器扩展**：自动在各 AI 平台创建 API Key

两者（桌面版与 CLI）共享同一数据目录 `~/.modelswap`，二选一即可。
