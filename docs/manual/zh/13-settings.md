# 13. 设置参考

![设置页](../images/settings.png)

| 分区 | 内容 |
|------|------|
| 语言与外观 | 界面语言（中/英）、深浅模式、5 种配色风格 |
| 设备同步 | 局域网设备配对与状态（见 11.3）、自动同步开关 |
| 云备份 | 云同步平台配置与测试、同步密码（见第 11 章） |
| 配置历史 | 配置快照与恢复（见第 12 章） |
| 浏览器插件 | 扩展连接状态、打开扩展目录、安装步骤 |
| 关于与诊断 | 版本与服务健康、检查更新、复制诊断信息 |
| 操作记录 | 操作日志：搜索、按状态筛选、导出 JSON |

桌面版发现更新后，会在窗口左上角显示下载图标；悬停可查看更新说明，点击下载后会自动安装并重新打开应用。

报问题时，诊断页的**复制诊断信息**会生成一份摘要（版本、服务状态、已装 Agent、近期失败记录等，**不含任何密钥**），直接粘贴即可。
