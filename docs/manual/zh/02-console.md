# 2. 控制台总览

![快速启动页](../images/quick-start.png)

| 页面 | 用途 |
|------|------|
| 快速启动 | 首页驾驶舱：Agent 切换、Provider 启用、今日用量 |
| 密钥管理 | 加密密钥库：手动添加、自动创建、绑定项目、同步 |
| 模型管控 | 40 个 Provider 预设：端点、认证方式、模型列表、套餐 |
| 用量统计 | 30+ 个订阅/余额来源的查询与告警 |
| Agent 配置 | 10 个 Agent 的配置适配与模型一键切换 |
| 模型目录 | 全平台官方定价与能力对比 |
| 设置 | 语言外观、设备同步、云备份、配置历史（快照恢复） |

界面语言与深浅模式在 **设置 → 语言与外观** 中切换。
