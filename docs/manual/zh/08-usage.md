# 8. 用量查询与告警

![用量统计页](../images/usage.png)

用量统计页覆盖 37 个订阅/余额来源，不用逐个打开平台控制台就能看清余量。

## 8.1 页面总览

- 两个标签页：**订阅额度**（按 5h / 周 / 月窗口展示剩余百分比与重置时间）与 **API 余额**（充值余额，余额偏低标红）
- 顶部概览卡：已读取数量、「需关注」（告警数）、「待处理」（未配置或仅控制台可查的平台数）
- 未配置、未登录或仅支持控制台查询的平台收在「待处理与外部查询」折叠区，卡片带官方控制台外链

## 8.2 刷新

- 工具栏**全部刷新**并发拉取所有平台；单卡右上角可单独刷新
- 自动轮询默认每 5 分钟一次；有窗口即将重置时加速到每分钟
- 少数平台（如 OpenCode Go）为手动刷新型，不支持自动轮询

## 8.3 告警

- 订阅剩余 ≤30% 黄色告警、≤10% 红色告警；API 余额 ≤ $1 报警；窗口即将重置且还有余量时会提示
- 红色告警触发**桌面通知**（首次需授权通知权限，同类告警按平台+窗口去重，不会刷屏）
- 告警集中在页头「需关注」，点条目跳到对应卡片

## 8.4 配置查询凭证

余额查询类平台（火山引擎、通义千问/阿里云、百度千帆、腾讯云）需要在云控制台创建**只读**的查询凭证：点卡片右上「配置」有分步图文引导（建 IAM 用户 → 绑定只读策略 → 粘贴 AK/SK），凭证作为复合密钥存入密钥库，保存时自动测试连通性。

首页「快速启动」也有今日用量摘要。
