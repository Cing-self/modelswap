# ModelSwap 使用手册

ModelSwap 是 AI Agent 的密钥与模型管控台：本地加密密钥库、41 个模型平台预置、10 个 Agent 适配、37 个订阅与余额来源查询，配合浏览器扩展可以**一键自动创建 API Key**。本地优先，数据不出你的电脑（除非你主动开启同步）。

---

> 本手册发布于 docs.modelswap.app，本目录是它的源文件（由 `scripts/build-docs-site.mjs` 构建）。章节按编号分列于此目录（01–15），按「快速上手 · 密钥管理 · 模型配置 · Agent 配置 · 数据与安全 · 参考」六组划分。
