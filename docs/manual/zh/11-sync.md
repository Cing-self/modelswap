# 11. 多设备同步

## 11.1 云同步

端到端加密的跨机器同步。云端只存密文，主密钥始终在本机；所有机器输入**相同的同步密码**即可互相同步。支持平台：iCloud、WebDAV、Cloudflare（R2 / KV / D1 / 密钥库）、Supabase、火山引擎。

在 **设置 → 云备份** 中配置平台与同步密码后：

```bash
modelswap vault push                 # 推送密钥与 Agent/Provider 配置到所有已启用平台
modelswap vault pull                 # 拉取各平台最新数据并合并到本地
modelswap vault test cloudflare-kv   # 测试某平台连接（如 supabase、cloudflare-kv）
```

## 11.2 自动同步（推荐）

在设置中开启「自动同步」后，无需手动推送/拉取：

- 本地改动（密钥、Agent 配置、模型商配置）**10 秒后自动加密推送**
- **所有已启用的平台会同时推送**，互为备份；拉取时自动选取各平台中最新的一份数据
- 每 **5 分钟**自动检查远端，有新版本就合并（按修改时间新者胜，本机较新的改动永不被旧数据覆盖）
- 服务启动时先合并远端、再补推本地未推送的改动
- 首次开启会立即推送一次建立云端基线

## 11.3 局域网设备同步

同一局域网内的电脑之间直接同步，不需要任何云平台账号。入口：**设置 → 设备同步 → 添加设备**。

> 前提：两台电脑连着同一个局域网，且使用**相同的同步密码**（它是端到端加密的根；主设备没设置过的话，发起时界面会先要求设置）。

**① 在数据所在的那台电脑上发起（主设备）**

1. **设置 → 设备同步** → 点击 **添加设备**
2. 选择 **「从本机发起」**（本机已有数据）
3. 界面生成一条 `modelswap-lan://` 配对码（一次性、限时有效），点击复制
4. 保持这台电脑的 ModelSwap 开着；对端接入后会自动提示「配对成功」

**② 在新电脑上加入**

1. 新电脑安装并启动 ModelSwap，进入 **设置 → 设备同步 → 添加设备**
2. 选择 **「加入已有同步」**（本机是新设备）
3. 粘贴主设备的配对码，输入与主设备**相同的同步密码**，点击 **连接**

**配对之后**

- 设备列表实时显示对端在线状态；局域网对端就是一个同步平台——手动 `modelswap vault push` / `pull` 和自动同步都会带上它
- 数据端到端加密；主设备 IP 变化（如路由器重新分配）后重新配对一次即可
- 首次连接被系统防火墙拦截时，允许 ModelSwap 的入站连接（默认端口 3790）
- 可与云平台同时启用、互为备份；设备同步区的 **⋯** 菜单可重置访问令牌或关闭局域网同步
